# TMS Mobile - Build Output

This repository contains the built web assets for the TMS Mobile application.

## Purpose

This is a separate repository that only contains the compiled/built files from the main TMS Mobile source code repository. The build output is generated by Vite and automatically deployed to GitHub Pages.

## How it works

1. Source code is maintained in the main repository
2. Build process outputs files to this `web/` directory
3. This repository tracks only the built files
4. GitHub Pages or similar can deploy directly from this repository

## Building

From the main repository, run:

```bash
npm run build
```

The output will be generated in this directory.
